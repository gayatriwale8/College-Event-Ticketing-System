# College-Event-Ticketing-System
A simple college event ticketing management system using Python and MySQL.
College Event Ticketing Management System

Project Description

This project is a simple College Event Ticketing Management System developed using Python and MySQL. It helps manage college events and student ticket bookings.

Technologies Used

- Python
- MySQL
- MySQL Connector

Features

- View available events
- Manage student details
- Manage event ticket bookings
- Connect Python with MySQL database

Requirements

- Python
- MySQL Server
- MySQL Connector library

How to Run

1. Install Python and MySQL.
2. Install the required library using "pip install mysql-connector-python".
3. Create the required database and tables in MySQL.
4. Configure the MySQL connection details in the Python code.
5. Run the Python file.
